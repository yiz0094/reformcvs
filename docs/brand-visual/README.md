# 리폼편의점 브랜드 비주얼 작업 기록

2026-11-04 기준. 색상은 비교 중이며 최종 확정되지 않았습니다. 현재 운영 프런트엔드의 색상을 변경한 작업이 아니라, 브랜드 방향과 첫 화면 시안을 보존한 자료입니다.

## 고객과 브랜드 방향

- 첫인상: “부담 없이 나도 한번 해보고 싶다.”
- 중심 경험: 재미있게 내 옷을 꾸미고 나만의 개성을 표현하기.
- 직접 꾸미기, 추천받기, 작가와 함께 만들기를 모두 열어두고 고객이 선택합니다.
- 화면은 깔끔하고 세련되게, 따뜻함은 사람과 말투에서, 재미는 작은 포인트로 전달합니다.
- 옷과 작품이 중심입니다. 넓은 화이트 바탕에 차콜 글씨를 사용하고 두 포인트 색의 면적은 작게 유지합니다.

## 색상 진행 상태

| 구분 | 값 | 상태 |
| --- | --- | --- |
| 기본 배경 | `#FFFFFF` | 화이트 방향 합의 |
| 본문 | `#303236` | 차콜 예시값 |
| 초록 | `#23552B` | 최신 비교에서 유지 요청 |
| 깊은 보라 | `#574F82` | 사용자 제공 참고값. 무겁다는 피드백 |
| 부드러운 보라 | `#79719B` | 최신 제안. 아직 선택 확정 전 |

사용자는 브랭섬홀 아시아 홈페이지에서 확인한 보라 `#574F82`, 초록 `#23552B`를 참고값으로 제공했습니다. 해당 사이트의 현재 색상을 독립 검증한 기록은 아닙니다.

마지막 요청은 초록을 유지한 채 보라를 같은 색감에서 조금 밝고 부드럽게 조정하고 기존 색과 비교하는 것이었습니다. 최신 시안은 사진·문구·배치를 동일하게 유지한 두 화면입니다. 제안 보라 위 흰색 글자의 계산상 명암비는 약 4.52:1입니다.
