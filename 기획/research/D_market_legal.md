**경쟁 구조 해석**
1. 온라인 수선 플랫폼(모두의수선·바지단·Laundry24)은 **기능 수선(기장·허리·지퍼)** 에 집중하며 '디자인 리폼'·'미리보기'가 없다.
2. 명품 플랫폼(패피스·럭셔리앤올·숨고)은 **사진 기반 견적 매칭** 이 핵심이고, 작업 결과 미리보기는 제공하지 않는다. 패피스는 AI를 '운영 효율(견적 추천)'에 쓰지만 시안 생성에는 쓰지 않는다.
3. 브랜드 자체 수선(유니클로·파타고니아)은 **자사 제품 한정** 이며 디자인 변경을 명시적으로 배제한다(파타고니아).
4. 따라서 **"어떤 브랜드의 옷이든 + 우리 디자인 템플릿 + AI 미리보기 + 수거·반송 원스톱"** 은 국내에 직접 경쟁자가 없다. 다만 '리폼은 수선보다 단가가 높고 소비자 기대치(시안=실물)가 커서' 클레임 관리가 수익성의 핵심 변수다.

**대법원(2026.2.26, 2024다311181)** — 법률신문·한경·헬프미
- **원칙**: 소유자가 **개인적 사용을 목적**으로 리폼을 요청하고 리폼 제품이 **거래시장에 유통되지 않는** 경우, 상표가 그대로 남아 있어도 상표를 표시하는 행위는 상표법상 '상표의 사용'이 아니다 → 침해 불성립. 리폼업자가 소유자 요청을 받아 리폼 후 반환한 경우도 동일.
- 근거: 소유권(사용·수익·처분), 스스로 리폼하기 어려운 소유자가 전문가 조력을 받는 것도 정당한 권리 행사, **리폼업자의 대가는 판매대금이 아닌 서비스 대가**, 소비자 후생, 자원순환·환경적 지속가능성(보도에 따라 표현의 자유 언급).
- **예외('특별한 사정')**: 형식상 개인 사용 리폼이라도 리폼업자가 **일련의 리폼 과정을 실질적으로 지배·주도하면서 자신의 제품으로 상거래에 제공·유통**시켰다고 볼 사정이 있으면 침해 성립 가능. 판단 요소 5가지:
  1. 소유자의 리폼 요청 경위와 내용
  2. 리폼 제품의 목적·형태·개수 등에 대한 **최종 의사결정 주체**
  3. 리폼업자가 받은 **대가의 성격**(가공비 vs 판매대금)
  4. **재료의 출처와 비중**(고객 제공 vs 업체 조달)
  5. 리폼 제품의 **소유관계**
- **증명책임은 상표권자**에게. 소유자가 유통 목적을 알았거나 알 수 있었음에도 서비스를 제공했다면 **공동 책임** 가능.
- 의의: 리폼 행위의 상표권 침해 여부에 대한 **대법원 최초 판단**.

**파기환송심(2026.9.10 변론)** — 한국경제 2026.9.11
- 루이비통 주장: 업체가 붙인 '재활용' 라벨은 자사가 만들지 않은 위조품; 고객 제품에 없던 **라벨·부속품을 업체가 별도 조달**; **인기 신제품을 반복 복제**; **리폼 가능 모델을 홈페이지에 게시**; 카카오톡 대화 증거 → "리폼이 아니라 사실상 제작". 수리 자체는 소비자 권리로 인정.
- 리폼업자 주장: 모아둔 장식·로고 라벨 재활용, 손상 부위만 새 가죽; **디자인 선택·작업 지시는 고객**, 자신은 기술 작업만; 중고 판매는 고객의 별개 거래.
- 쟁점: 소유자 리폼의 자유 범위 / 어느 시점부터 전문업자의 '상표 사용·상품 제작'인가 / '특별한 사정' 존재 여부.

### 3.4 서비스 약관·안전장치 제안 (상표 관련)
1. **개인 사용 목적 확인 조항**: "본 서비스는 고객 소유 의류를 고객의 개인적 사용 목적으로 가공하는 서비스이며, 가공 결과물의 판매·대여·위탁판매·플랫폼 등록을 금지한다." 위반 시 손해배상·면책.
2. **고객 의사결정 기록**: 템플릿 선택, 옵션(위치·크기·색) 조정, 시안 승인, 작업지시 확정의 각 단계를 타임스탬프와 함께 저장(분쟁 시 '최종 의사결정 주체=고객' 입증).
3. **재료 출처 기록**: 작업 명세서에 '고객 제공 재료 / 업체 제공 무지 재료' 구분. 브랜드 로고·라벨·금속 부속의 추가 조달 금지.
4. **리폼 표시**: 결과물에 '리폼 편의점 Reformed' 자사 라벨 부착(브랜드 라벨 옆이 아닌 내측), 영수증·보증서에 "원제조사와 무관한 가공품" 명시.
5. **광고 가이드**: 특정 브랜드명·로고를 광고 카피·썸네일에 사용 금지. 포트폴리오는 고객 동의 + 로고 마스킹.
6. **브랜드 리스크 등급**: 명품 모노그램·로고 반복 원단(루이비통 모노그램·다미에, 구찌 GG 등)은 '고위험' 등급으로 별도 심사·제한 템플릿만 허용.
7. **환송심 결과 반영 절차**: 2026.11.12 선고 후 2주 내 약관·템플릿 정책 재검토 일정을 기획서에 명시.

## 4. 기타 법률 이슈

### 4.1 AI 생성 이미지(시안)의 저작권·귀속
- 문체부·한국저작권위원회 **'생성형 인공지능 활용 저작물의 저작권 등록 안내서'(2025.6 말 공개)**: 등록 요건은 **'인간의 창작적 기여'**, 판단 기준은 **통제가능성·예측가능성**. 프롬프트만으로 생성한 결과물은 창작적 기여 인정 가능성 낮음. 반복 수정(인페인팅), 의도적 선택·배열은 인정 사례 있음. 생성 과정 기록(영상 등) 권장. 등록 신청 시 AI 생성 포함 사실을 기재. 출처: 전자신문 2025.7.1 https://www.etnews.com/20250701000303 ; 디지털인사이트 https://ditoday.com/gai-copyright/
- **함의**: (1) AI가 자동 생성한 시안 자체는 저작권 보호가 약하므로 **경쟁사가 시안 스타일을 모방해도 저작권으로 막기 어렵다** → 회사 '디자인 템플릿 원본(사람이 그린 도안·자수 패턴·패치 디자인)'을 별도 저작물·디자인권으로 관리. (2) 약관에 "시안 이미지의 권리는 회사에 귀속(또는 비독점 이용 허락), 고객은 개인 열람·주문 목적으로만 사용" 명시. (3) 고객 사진(원본)은 고객 저작물이므로 **이용 허락 범위**를 명확히.

### 4.2 AI 기본법(2026.1.22 시행) — 투명성 의무
- 법명: 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」, 2026.1.22 시행. 과기정통부 **'인공지능 투명성 확보 가이드라인'** 으로 구체화. 출처: 뉴시스 2026.1.21 https://mobile.newsis.com/view/NISX20260121_0003485509 ; 국민일보 https://www.kmib.co.kr/article/view.asp?arcid=1768984300
- 의무 주체: **인공지능사업자**(생성형 AI 제품·서비스 제공자). 리폼 편의점이 AI 시안 기능을 제공하면 해당.
- 의무 ① **사전 고지**: 생성형 AI 기반 운용 사실을 약관·앱 화면에 고지.
- 의무 ② **생성물 표시**: 결과물이 다운로드·공유로 **서비스 밖으로 반출되는 시점**부터 가시적 워터마크 또는 메타데이터(기계판독) 표시. 기계판독만 쓰면 다운로드 시 1회 이상 안내. 서비스 UI 안에서만 보여주면 결과물별 표시 의무 없음(이용 전·중 안내로 충분).
- 딥페이크(실제와 구분 어려운 결과물)는 가시적 표시 필수 — **고객 얼굴·신체가 포함된 시안은 딥페이크 요건에 해당할 수 있으므로 가시적 표시 권장**.
- 과태료 최대 3,000만 원(제40조), **1년 이상 계도기간**(사실조사·과태료 유예). 2026.7.21 개정법·시행령 추가 시행 보도 있음(세부 **[미확인]**). 출처: 팩트레이스 https://factrace.kr/issues/korea-ai-basic-law-governance-2026 ; 경향 https://www.khan.co.kr/article/202607210908001/
- **함의**: 시안 이미지에 'AI 생성 시안' 워터마크 + 메타데이터를 기본 적용. 이는 표시광고법·소비자 분쟁 방어에도 유리.

### 4.4 맞춤제작 상품의 청약철회 제한 (전자상거래법 제17조)
- 원칙: 재화 공급받은 날부터 **7일** 내 청약철회(제17조 제1항). 표시·광고·계약 내용과 다르게 이행된 경우 **공급일 3개월 / 안 날 30일** 내 철회(제3항) — **AI 시안과 다른 결과물**은 여기에 해당할 수 있음.
- 제한: 제2항 제6호 + 시행령 제21조 — **'소비자의 주문에 따라 개별적으로 생산되는 재화'** 로서, 청약철회를 인정하면 사업자에게 회복 불가능한 중대한 피해가 예상되는 경우, **사전에 해당 거래 사실을 고지하고 소비자의 서면(전자문서 포함) 동의**를 받은 경우. 제6항 조치(명확한 표시 등) 미이행 시 철회 가능. 제17~19조 위반 소비자 불리 약정 무효(제35조). 환급은 반환일로부터 **3영업일**, 지연이자 연 15%(제18조). 단순변심 반품비는 소비자, 하자·광고 상이 시 사업자 부담. 출처: 찾기쉬운 생활법령 https://www.easylaw.go.kr/CSP/CnpClsMain.laf?csmSeq=835&ccfNo=4&cciNo=1&cnpClsNo=2 ; 법제처 https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1021872703 (2026.7.21 시행, 법률 제21312호)
- 실무 주의: 소비자24 상담례는 "1:1 주문 방식"만으로는 제한 대상이 아니라고 봄(주문자의 특별한 취향이 반영돼야 함). 공정위는 주문제작 아닌 상품에 철회 불가 고지한 사업자에게 시정명령·과태료 부과 사례(디지털데일리 2024.5.20 https://m.ddaily.co.kr/page/view/2024052009122186446 ). 한국소비자원(2018.11) 주문제작 피해 291건 중 의류 45.4%, **청약철회 거부 37.8%는 전부 법상 주문제작으로 볼 수 없는 사례**, 색상·디자인 상이 61건. https://www.kca.go.kr/home/sub.do?menukey=4002&mode=view&no=1002727940
- **함의**: 리폼은 고객 의류를 되돌릴 수 없게 가공하므로 전형적 '개별 생산'에 해당할 가능성이 높으나, **(a) 주문 확정 전 "작업 착수 후 청약철회 불가" 고지 + 전자문서 동의 체크, (b) 수거 후 작업 착수 전까지는 취소 가능(가분적 단계) 명시, (c) 시안과 현저히 다른 결과는 재작업·환급 기준 별도 제시**가 필요.

### 4.6 세탁·수선 관련 소비자분쟁해결기준
- 현행 **소비자분쟁해결기준(공정위 고시 제2025-14호, 2025.12.18 시행)**. 세탁업 항목: 배상액 = **구입가격 × 배상비율**(내용연수·사용일수별 표, 95%→10%), 구입가·구입일 입증 불가 시 **세탁요금의 20배**, 세트 의류 배분(상의 65%/하의 35%), 하자 시 사업자 비용 원상회복→불가 시 배상. 세탁업 표준약관: 인수 시 하자 확인 의무(제3조), 하자보수·배상 청구는 **인도일부터 6개월 내**(제10조), 고객 책임 입증은 사업자. 출처: https://www.law.go.kr/LSW/admRulBylInfoPLinkR.do?admRulNm=소비자분쟁해결기준&bylBrNo=00&bylCls=BE&bylNo=0002 ; 생활법령 https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=716&ccfNo=3&cciNo=2&cnpClsNo=1
- **수선·리폼 전용 기준은 없음** → 분쟁 시 세탁업 기준이 준용되거나 민법 도급 법리로 처리. 
- **함의**: (1) 수거 시 **인수증(품명·구입가·구입일·기존 하자 사진)** 전자 작성, (2) 분실·훼손 시 배상 기준을 약관에 세탁업 배상비율표 준용으로 명시, (3) 고가 의류는 신고가액 기반 배상 한도·보험 검토, (4) 리폼 자체가 '가치 변경'이므로 "리폼 후 중고가 하락"은 배상 대상이 아님을 고지.
